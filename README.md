# Poems of Love

A heartfelt Next.js poetry library built as a personal devotion collection. The project presents poems as a bookshelf of soft, romantic book spines and immersive reader experiences.

## Features

- Shelf-inspired layout for browsing poems
- Interactive poem cards with dedicated reader views
- Responsive design built with Next.js and custom CSS
- Personal dedication theme to express devotion and love

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure

- `app/` — main Next.js routes, pages, and global styles
- `components/` — UI components for the poem shelf and reader
- `data/` — poem data used throughout the site
- `public/` — static assets and images

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build the app for production
- `npm run start` — run the production build locally
